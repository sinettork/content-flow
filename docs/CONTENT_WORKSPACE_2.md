# ContentFlow Content Workspace 2.0

ContentFlow now treats content as the core work object and presents its operational surfaces as connected views.

## Core mental model

Plan → Create → Review → Schedule → Publish → Analyze

## Content workspace views

- My Work — ownership and due-date queue
- Content — searchable list and bulk operations
- Board — workflow/status management
- Calendar — publishing schedule and agenda
- Campaigns — grouped content planning
- Assets — creative library

These views share one navigation rail and remain linked to the same content records.

## Outside the workspace

- Dashboard — workspace overview and attention center
- Approvals & Publishing — operational review and recovery
- Automation — event-driven rules and channel readiness
- Reports — operational and delivery metrics
- Team — people, roles, and workload
- Settings — workspace configuration

## UX intent

Do not treat Board, Calendar, My Work, and Content as separate products. They are different working perspectives on the same content operation.

The sidebar reinforces this hierarchy, while each core view provides a consistent view switcher.

## Next product direction

The next architectural step can evolve the Content detail screen into the canonical work object page: content brief, platform variants, assets, comments, approval state, schedule, publishing result, and activity in one place.


## Canonical content-item review flow

1. Create content and optionally attach creative files from the New/Edit screen.
2. Open the Content Item to see its creative files, platform copy, comments, versions, activity, and workflow.
3. Add new creative files as revisions directly on the Content Item.
4. Send the item for review. Reviewers can open the same item from Approvals & Publishing.
5. Reviewers use comments plus Request changes / Approve.
6. After changes are requested, the owner updates the same item and resubmits.
7. Approved content moves into scheduling and publishing.

The global Assets page remains a reusable library. It is not the primary review workspace.
